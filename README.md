# 🚀 Data Base Users - Front-end

Interface web desenvolvida para realizar o gerenciamento de usuários conectando-se a uma API CRUD.  
O sistema permite cadastrar, listar e deletar usuários de forma simples e intuitiva.

## ✨ Funcionalidades

✔️ Cadastro de usuários  
✔️ Listagem de usuários cadastrados  
✔️ Exclusão de usuários  
✔️ Integração com API REST  
✔️ Navegação entre páginas  
✔️ Interface moderna e responsiva

## ⚙️ Como Executar o Projeto

### 📥 Clone o repositório

```bash
git clone https://github.com/cleissoncardoso38-collab/data-base-users.git
```

### 📂 Acesse a pasta do projeto

```bash
cd data-base-users
```

### 📦 Instale as dependências

```bash
npm install
```

### ▶️ Execute o projeto

```bash
npm run dev
```

---

## 🔌 Integração com API

Este projeto consome uma API CRUD responsável pelo gerenciamento dos usuários.

Para executar corretamente, o back-end precisa estar rodando localmente.

### ▶️ Executar API

```bash
git clone https://github.com/cleissoncardoso38-collab/crud-users-api.git

cd crud-users-api

npm install

npm run dev
```
